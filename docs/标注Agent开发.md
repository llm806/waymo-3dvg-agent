# 工作台使用与验收

安装、模型配置及启动命令见 [README](../README.md)。通过 <http://127.0.0.1:8000> 打开本机工作台。

## 创建和运行任务

1. 按官方训练集和验证集分别放置 Parquet 文件。新增数据后运行 `scripts.check_dataset` 和 `scripts.build_catalog`，再刷新工作台。候选目录记录待选目标，处理状态和可用描述数量在任务中统计。
2. 选择对应数据划分，设置目标数量后创建并开始任务。执行器忙时，已确认开始的任务进入队列。可单独取消排队中的任务。
3. 查看处理状态、已尝试目标、自动核验结果及模型调用。任务处理结束后仍可能包含未通过和失败样本，按明细判断可用范围。
4. 需要中断时使用“暂停”或“停止任务”，等待当前步骤保存及执行器退出。关闭或刷新网页不会停止后台任务。重新启动服务后，可通过原任务“继续标注”恢复。恢复保留历史结果和累计调用，结果未知的请求不重放。

默认每目标及同一轨迹跨任务累计最多 12 次调用。任务总额度默认不限，已有有限额度按原配置执行。

## 审核和返工

在任务结果中选择样本。用实际来源相机原图和同帧完整场景核对文本指向、外观、空间关系和原生三维目标。官方投影可辅助定位，实际可见部分以原图为准。点云预览可使用采样，导出保留完整点云。

| 操作 | 结果 |
| --- | --- |
| 审核通过 | 正确确认物体定位后记录审核结论 |
| 人工审批通过并纳入可用集 | 自动未通过的当前描述在正确定位并核实后可显式审批。审批绑定文本、来源帧和原生目标，原自动失败记录保留 |
| 提交反馈并修改 | 在原任务中返工，写明应修改的事实或措辞。已达目标时，先移除一条有效标注腾出名额 |
| 拒绝或废弃 | 从可用集和导出中排除该版本，原始数据仍保留 |

显式返工为当前版本及反馈分配新一轮最多 12 次调用，同一次提交重试不会重复增加额度。新版本仍须核验。若返工结束却未生成新草稿，旧文本只供查看和再次提交反馈。

## 导出和合并

1. 选择已完成且执行器已退出的任务，训练集和验证集分别导出。
2. 在解压目录中运行 `python loader.py --root .`。核对任一样本的描述、来源相机、完整点云和监督框能对应到同一帧。
3. 合并同一官方划分的分包时，重复样本应去重，版本或资源冲突应报错。同一驾驶片段不可跨训练集和验证集导入。命令见 [README](../README.md#加载与合并)。

## 删除和清理

在任务管理中勾选、预览，再确认删除。系统阻止删除所选活动任务，保护其他任务引用的场景、证据及账本。删除确认可选择是否将已处理物体重新加入候选池，重新加入仍受存续引用及累计额度限制。

原始数据、本地配置、模型调用、冻结执行记录和被引用的资产需要保留。清理前确认文件用途及引用，避免将持久化记录误当作临时缓存。

日常审核用于维护可用标注。独立评估的样本、指标及访问范围见[科研验收协议](科研验收协议.md)。
