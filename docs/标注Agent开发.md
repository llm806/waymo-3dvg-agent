# 日常使用与人工验收路径

核对日期：2026-10-21。安装和命令见 [README](../README.md)，实现边界见[实施任务清单](实施任务清单.md)。实时数量查询接口，不以旧截图或固定快照验收。

## 服务与数据

用户在项目根目录启动 `uv run uvicorn app.main:app`，打开 <http://127.0.0.1:8000>；助手不得启动或重启服务。关闭网页不会停止任务，正常退出前先暂停并等请求保存。

新增数据核对各组件与重名冲突后，运行 `scripts.check_dataset` 和 `scripts.build_catalog`，再刷新网页。候选不等于已经通过标注，不要求提前转换全部帧。

异常退出的 running 批次可在旧租约过期且代码／目录／模型一致后恢复；主动暂停、停止和未启动不自动执行。后端代码更新时先由用户重启，再继续任务。

## 自动标注验收

执行器忙时，新任务点击开始进入队列，显示排队位置；正常完成后自动接续，重复点击不重复排队，可取消单项。当前任务暂停／停止或共享故障会挂起后续队列，继续后接续；重启保留队列，但配置改变需再次开始确认。刷新／关闭网页不影响后端执行。

1. **任务与额度：**默认模型 `qwen3.8-flash`，实际配置以运行记录为准。期望数量 1–2000，默认目标／模型并发 4／4，转换串行。默认无任务总上限，每目标／轨迹累计默认最多 12 次；失败补选。通过数、尝试数、候选池分开显示。
2. **身份绑定：**点云、原图、来源相机及原生框属于同一采集帧。绿框为真值／官方投影，紫框为文本目标；官方投影不能称作独立原生 2D 框。身份不一致应停止配对展示。
3. **实际可见性：**局部遮挡、出画、背面标志牌不直接拒绝；可见表面必须属于实际目标。无点、完全隐藏、身份不明或无法消歧时保留原因，不能写成成功。
4. **自然英文：**默认模型生成，短而通顺；优先细分类别、自车方位和可靠地标关系，禁止 bottommost／topmost、上下排序及画面角落用语；新草稿保留最多三项确认的显著外观及可靠自车方位，不能只因 leftmost／rightmost 已唯一而删空属性。新增形状／颜色不能偷换比较组；局部草稿修正保留原文并仍需双轮核验。确认的车型／部件、体色、衣着／头盔和显著特征正确。地标描述本身应唯一，关系有证据；属性＋自车／原生地标关系足够唯一时省略相机填充，必要图像视角保留；局部简化须保留原文并完成双轮核验；图像左右明确相机，自车方位不与其混用。未知属性不等于不存在。新记录在模型调用前／成功保存前检查任务身份链；准备凭据与物体链接应一起提交，注入中断后不能留下半条关联，失败记录不得计为成功。
5. **不合格语言：**新文本不应依赖轮廓最高／最低、像素边缘、中心高度等抽象表达，不重复堆叠比较组；不能猜测建筑、运动或意图，不能使用具体距离、最近／最远或对象 ID 暗号。
6. **完整核验：**目标小批次可在实际证明唯一后跳过无用观察，不能把规划假设算作证据、删除未知竞争者或跳过双轮核验。候选仍须外观及两轮盲解析／工具定位；仅符号歧义时可在原额度内使用两轮完整原图和全部匿名候选盲定位复核，记录模型参与的协议。自动未通过版本也可在正确人工定位确认后明确审批纳入可用集，保留自动失败原因与审批绑定。换相机、同轨迹换帧、补看和改写受原预算限制，最终监督绑定实际选定的一帧。低额度本地候选不能绕过核验。
7. **继续任务：**同一任务保留编号、名称、创建时间、原目标、成功文本与累计进度。未完成工作回样本起点，历史输入输出及额度留账，未知结果请求不重复发送。新代码／配置记录内部执行修订，旧成功记录不改写。后台仍加载旧代码时应提示 `backend_restart_required`。

暂时 HTTP 错误应退避，单样本错误隔离；认证、存储等共享故障保留状态与原因。不能用软件回归代替连续运行可靠性结论。

点云可切换聚焦／完整场景、相机视角／自由三维／俯视，图像可查看未叠框原图。展示采样不能替代导出的完整点云，也不证明滚动快门下像素级重合。

## 日常审核与返工

随机抽取待审样本或按任务处理索引选择；索引不是轨迹 ID 或全局候选排名。人工定位先隐藏预期目标，选择可确认身份的物体并确认，然后提交审核：

- **通过：**须正确完成定位确认；自动核验不完整的草稿仍不能导出。
- **拒绝：**填写具体原因；Agent 返工在原任务内重试同一原生对象，不新建任务，携带旧文本和反馈进入模型生成上下文，为本次返工分配最多 12 次新调用；同一次反馈重复提交不重复加额，历史调用与费用保留，新描述仍须通过双轮核验，通过后计入原任务；候选耗尽但未达目标仍可返工，达到目标时须先手动删除一条有效标注，腾出名额后再重试。
- **废弃：**排除该样本版本，不删除原始数据。

审核绑定文本／场景版本，刷新后状态和待审统计应一致。返工新版本独立保存，旧失败不改写，同一被拒文本不能原样返回为成功。日常即时反馈会暴露目标，不计入独立盲评。

## 删除与清理

管理中勾选任务、预览再确认；只删除选中任务，不连带删除续作。保留存续任务继承样本、过程、原目标和累计额度，多级／分支引用不重复计费；最后关联任务删除后回收无引用历史。

确认框可选“将已处理物体重新加入候选池”。含已完成任务默认不勾选，未完成任务默认勾选；未处理物体不受影响。不勾选时保留轻量轨迹排除信息；勾选仍受其他任务记录和累计额度限制。历史导出清单可一次性恢复排除信息，导入后不依赖这份临时文件。

所选活动任务禁止删除，其他任务不必暂停；无关任务进度不使确认反复失效。活动执行器期间保留共享场景／证据和索引。取消不改记录，失败回滚，中断事务可在服务启动时恢复。补核验、开发核验后代不能遗漏，独立运行与共享引用保留。

核对与删除会显示阶段、当前记录／目录进度和已清理文件数；历史记录首次建立引用缓存可能较慢，之后仅重算变化记录。文件扫描、暂存和清理不占数据库写事务；提交前若发现新增引用，会恢复文件并要求重新核对。其他任务可继续保存模型结果及续期，活动期间保留共享日志。

不要为让候选数相等而清空合法历史或额度。临时／工具缓存可以清理，原始 Parquet、配置、运行依赖和有效持久化资产保留；Windows 文件占用由用户正常重启释放。

## 导出与合并验收

只选已完成且执行器退出的任务；排除模拟调用、失败草稿、无文本、核验不完整及人工拒绝／废弃版本，同轨迹选最新有效标注。

逐条检查原图、文本来源相机、完整点云、标定与同帧原生目标框对应。每条输入只用一个来源相机，场景可保存被引用相机的并集；对象清单与框属于监督。

公开包使用固定精简结构，无 schema_version、quality、method_version 或内部任务来源；内部质量记录与门槛不变。以包内 merge.py 合并，重复导入不增样本；同场景相机合并，版本／资源／用途冲突和兄弟集合 context 重叠明确拒绝，失败后原数据可读。loader.py 无需原项目或 SDK。

训练数据放 waymo_trainset，验证数据放 waymo_valset，各保留 13 个组件目录及官方 training_／validation_ 文件名前缀。创建任务选择对应集合，候选只显示对应来源；返工继承类型。训练／验证混选导出须提示分开处理，默认 ZIP 名称随任务类型，类型不符的请求拒绝。转换和样本保留真实 official_split，不从 training 随机拆分。

## 独立研究

`/api/research` 使用冻结 cohort、先锁定定位、记录目标暴露并 seal 报告的独立流程。评估者须事前未见目标，冻结前不反馈答案。同方法校准与评估使用不同 context；日常审核和内部测试不能代替独立盲评或下游自由框预测评测。门槛见[科研验收协议](科研验收协议.md)。
