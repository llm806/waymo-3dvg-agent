# 科研验收协议

核对日期：2026-10-21。本文区分内部诊断、人工审核、独立质量与下游模型性能。使用见[人工验收路径](标注Agent开发.md)，能力见[实施任务清单](实施任务清单.md)。

## 任务与证据

日常输入是完整单帧点云、英文 referring expression、实际来源相机的一张同帧原图及身份／标定；监督为原生 7-DOF 框。轨迹用于选帧、去重和额度，不构成时序训练输入。内部多视角证据不代表每条训练样本使用全部图像。

官方 C/T/O/V 投影身份、实际点支持与原图可辨认性共同约束标注。局部遮挡／出画不直接否决，但不能借遮挡者属性或推测隐藏部分。未知、零点和未观察竞争对象保留。

默认模型为 `qwen3.8-flash`，具体实验以冻结记录中的实际模型与端点为准。新生成策略保留最多三项确认的显著外观与可靠自车方位，缺失或冲突属性不编造；冻结历史文本不回写。模型写自然英文；低剩余额度仅可对简单已核验方案本地生成候选。按需观察只改变证据获取顺序与早停，不改变完整竞争池或最终核验；规划假设不算观察结果。草稿的比较范围修正须记录原文且重新完成双轮核验，不将它混称独立质量认证。两轮盲解析与确定性几何／视觉筛选属于 **GT-candidate 内部诊断**，不是独立认证，也不是网络从原始输入预测自由 3D 框的成绩。规则、提示、预算或模型变化须绑定冻结方法，历史成功率不跨方法直接拼接。

## 结果层级与指标

| 层级 | 用途 |
| --- | --- |
| 自动诊断通过 | 最终文本、必要外观／准入和两轮定位通过，可按日常规则导出 |
| 日常人工审核 | 定位确认后接受／拒绝／返工／废弃，影响导出；可能暴露目标 |
| 独立盲评接受 | 事前未见目标的评估者在冻结协议下完成唯一定位和独立判断 |
| 受控认证发布 | 同方法、不同片段校准／评估满足固定门禁后，发布独立接受的校准样本 |

人工接受不能绕过自动核验，认证发布不能改写旧诊断。日常随机审核与即时反馈不进入独立盲评分母。

| 指标 | 分母与解释 |
| --- | --- |
| 产出覆盖 | 有文本目标／声明目标范围；另列目录、候选、尝试、失败、弃权、预算跳过与未尝试储备 |
| 内部定位通过 | 双轮工具定位通过／有文本目标，仅为内部诊断 |
| 独立定位 | 独立评估者唯一选中原目标／独立有效回答 |
| 独立联合接受 | 唯一定位、事实正确、输入足够且源对齐接受／独立有效回答 |
| 错误风险 | 自动通过候选中独立不接受数／独立检查数，报告名义 95% Wilson 区间 |
| 成本与吞吐 | 新增请求、预留、token、耗时、活跃时间与吞吐；复用和人工工作分开 |

没有独立回答表示未测量。缺失 usage 不算零成本，未核对账单不报告货币费用。仅准备任务与合成测试不混入真实文本质量分母；局部性能倍数不等于整批端到端加速。

## 独立盲评

`/api/research` 提供 cohort、localization、answer、seal 和 releases。

1. 从已结束、无活动执行器的真实批次按事先声明 seed（默认 42）、文本阶段和规则冻结清单。无文本保留在覆盖分母，文本质量分母显式限定。
2. 隐藏预期目标、紫色强调、目标专属裁剪、生成线索、自动诊断和答案；候选匿名、等价展示，点云预览采样与目标无关。
3. 按冻结 case 输入提供 RGB／点云／文本，选择全部可能对象，多选或空选不算唯一正确。先锁定定位，再提交其它判断。
4. 记录事实、输入充分性、源对齐、评估者、原因和事前目标暴露。已见目标的回答排除独立分母，并报告排除数。
5. 回答齐全后 seal；冻结前不反馈答案，冻结后不可编辑。

当前协议为 `blind-native-candidate-multimodal-human-v2`，历史 v1 保留原协议。不同协议／方法不能混用证书；历史研究输入不能直接按日常单相机 ZIP 约定重新解释。人工选择原生候选框不是自由框预测，哈希／主键／点数／官方对应也不是外部像素对齐标定。

## 认证发布门禁

`app/quality/research.py` 固定最低要求：至少 30 个自动通过候选的独立回答，错误率名义 95% Wilson 上界 ≤10%；校准和评估报告都须满足。30 条全对也可能不满足上界，不能降低界面参数绕过。

校准与评估须使用不同 context、同一冻结方法、执行配置、盲评协议及声明规则。发布器和读取器复核来源、分母、区间与版本，不仅信任布尔状态。

仅发布实际独立接受且原句诊断通过的校准样本；评估 context 与 case gold 不进入训练包，未抽检对象不外推认证。反事实未覆盖或预算不足如实保留。

认证 ZIP 由 `/api/research/releases/{release_id}/training.zip` 提供，仍采用独立旧格式、完整点云／多路图像／标签／证书与报告；validation.json 是质量报告，不是验证集。保留内部证据／来源绑定，训练读取不要求重算全部文件哈希。

## 日常数据与研究边界

Waymo-3DRef 日常包只纳入所选已完成任务的真实模型最终成功文本和完整场景，排除人工拒绝／废弃与核验不完整版本，每轨迹最新有效标注。公开精简结构不输出 schema_version 或内部质量／方法／来源字段，内部门槛保留；日常合并不授予独立资格。

按官方 training／validation 分别准备数据，不从 training 再拆分。当前读取／转换仅支持 training；intended_split、导出按钮和目录名称不改变 official_split。兄弟集合 context 检查仅防误导入。

3D Acc@0.25/0.5、BEV Acc@0.25/0.5 由后续训练后的网络评测实现，不以当前工具定位代替，不在本项目新增训练适配。

可在相同目标、输入、验收器及预算下比较生成、竞争证据、地标、修复与补视角策略；初稿／最终配对盲评需不同且事前未见目标的评估者、完整冻结报告和相同目标集合。配对改善不等于完整消融或下游收益。

相邻帧、同轨迹、同 context 存在相关性，名义二项 Wilson 区间不能直接保证跨场景风险。数据扩充、回归、故障注入和冻结回放不能替代独立盲评、跨片段泛化或持续运行验收。
