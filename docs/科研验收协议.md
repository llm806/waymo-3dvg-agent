# 科研验收协议

评估对象为一条英文指代表达与同帧 Waymo 原生三维目标的对应关系。记录官方数据划分、目标集合、证据输入、抽样种子、模型配置、冻结方法和评估协议。方法变化后的结果分别报告。

## 质量层级

| 层级 | 用途 |
| --- | --- |
| 自动核验 | 系统结合外观、身份和几何关系执行两轮模型辅助定位，筛选可用标注 |
| 日常人工审核 | 核对并维护标注。显式人工审批可纳入日常导出，保留审批来源 |
| 独立人工盲评 | 在冻结样本上，以匿名原生候选开展定位和事实判断 |
| 受控发布 | 在校准集和评估集通过规定门槛后，发布符合条件的校准样本 |

## 工作台抽样评估

1. 预先确定固定目标数、官方数据划分、计划抽审数和审核者。生成完成后，从无人工干预且通过自动核验的交付中按冻结种子进行无放回抽样。实际抽审数受可用交付数限制。
2. 审核者凭描述和场景证据，在匿名原生候选中提交目标选择或无匹配。单条提交后可显示是否命中，全部选择锁定后才显示原生目标并核对文本事实。
3. 审核者可在提交该条判断后、报告封存前更正误点。目标揭示后保存的误点更正也计入同一条审核，指标以审核者确认的选择为准。若记录中存在事前目标暴露，人工盲审准确率不发布。工作台当前不采集审核者在系统外是否预先知晓目标。
4. 完成抽审后生成报告。审核链接、审核者标识和逐例记录仅分享给相应参与者。公开材料使用汇总指标和必要的方法说明。

| 指标 | 计算口径 |
| --- | --- |
| 自动完成率 | 无人工干预且通过自动核验的交付数 ÷ 固定任务目标数 |
| 人工盲审准确率 | 审核者确认的选择中唯一命中原生目标的数量 ÷ 实际抽审数 |
| 文本准确率 | 审核判定文本事实正确的数量 ÷ 实际抽审数 |

分母为零或协议不允许报告时，标记为未测量。汇报成本时区分真实请求次数、已报告的 token 用量与按单价估算的费用。

## 独立校准与受控发布

独立校准使用 `/api/research/cohorts`。在冻结评估队列之前确定用途、样本范围、种子和文本阶段。评估时保持目标匿名，先锁定定位，再判断事实正确性、输入充分性及源对齐，并记录事前目标暴露。已暴露回答从独立分母排除，单独报告。封存后以冻结报告为准。

受控发布要求校准集和评估集使用相同的冻结方法、执行配置与盲评协议，并来自不重叠的驾驶片段。两份报告均须满足以下要求。

- 至少独立审核 30 条自动核验通过的样本。
- 以自动核验通过、但独立盲评未接受的比例估计错误风险，名义 95% Wilson 区间的上界须不超过 10%。样本量条件和区间条件分别检查。
- 报告完整，事前目标暴露排除数为零。

发布仅包含原句通过自动核验且独立盲评接受的校准样本，评估样本和答案留在独立评估记录中。受控发布包和日常 Waymo-3DRef 包采用各自的结构和纳入规则。日常导出资格见[技术方案](waymo-3dvg-agent技术方案.md#waymo-3dref-导出契约)。发布门槛以[独立校准实现](../app/quality/research.py)为准，工作台指标以[抽样评估实现](../app/quality/paper_study.py)为准。

## 结果解读

- 自动核验通过率、内部测试和人工盲评使用各自的分母。报告抽样框、实际抽审数量、排除原因和置信区间。
- 同帧、同轨迹和同片段的样本可能相关，名义 Wilson 区间不校正这些相关性。跨片段泛化需以独立评估数据测量。
- 人工从原生候选中选框衡量候选定位。3D Acc@0.25/0.5 和 BEV Acc@0.25/0.5 留给下游自由框预测评测。
