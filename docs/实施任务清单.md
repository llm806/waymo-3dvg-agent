## 已实现

- `native-3d-spatial-relations-v1` 在主标注和返工中统一使用原生三维几何；停用新草稿的像素关系、画面排序和二维限定地标，保留图像外观／身份检查。三维上下要求高度分离及水平位置对齐，自车方位与车辆朝向分别核验。属性方案无需地标，唯一方案优先，失败后重选证据组合；历史记录不重写。

- `joint-target-landmark-v1` 联合核验目标属性与存在式车辆关系，地标不要求单独唯一，完整目标必须唯一；未知候选对仍保留。写作模型仅写句子，程序绑定所选声明，失败可回退为完整候选并继续双轮核验。完整场景匿名框按实际发送图像缩放，盲定位收到程序计算的全部来源车辆几何关系图及全体候选统一编号图／图块，返回支持组合并核验原生身份及朝向；不提示目标，旧运行保持原规则。

- 无新草稿的已结束返工可再次提交反馈，展示、审批与返工权限分离；请求绑定旧文本版本及当前失败运行，在原任务分配一轮额度，重复提交幂等，失败记录及累计调用保留。

- 中途颜色／身份复核后恢复原观察计划的未执行批次，暂停恢复保留批次索引；新增调用后重新保留写作及双轮额度。地标补看允许仍在目标竞争池的潜在地标，优先核实可靠车辆朝向关系及所需缺失属性，不改变地标独立唯一性要求。

- `compound-claim-entailment-v1` 从盲解析自身已明确的属性范围补齐遗漏的重复属性字段，保留原始输出和推导来源；显式冲突及未知竞争者仍拒绝，旧规则不变。重复失败文本与声明提前拦截，写作收到失败文本；只修正声明仍可核验。返工显示具体完整场景盲定位失败原因。

- 新证据 `vehicle-heading-landmark-v1` 使用独立唯一车辆地标的原生朝向、框间分离与横向对齐支持正前／正后方关系；相机地标保留视角及全部未知竞争者，缺少原生身份不猜测前后。补看规划考虑该关系的消歧价值，最终仍复核身份、地标唯一性及双轮盲解析。重复外观谓词仅在已有相同属性声明时整理并留痕；未知谓词和改写后遗留的排序声明提前拒绝，返工显示具体错误与不支持的原文片段。

- 官方同帧 C/T/O/V 投影身份，独立 camera_box 及点对应为辅助；完整保留原生、零点和未知竞争对象。
- 原图确认实际目标可辨认性，局部遮挡／出画不直接拒绝；预算内补看、换相机、最多尝试 3 帧。准备与运行阶段换帧日志共同绑定实际来源帧，查看／导出不误用原始候选时间；凭据缺失或冲突仍拒绝；准备凭据与物体关联原子提交，模型调用前／成功保存前共用展示与导出的轻量身份检查，失败不计成功。
- 默认模型写自然英文，以已核验事实与唯一方案作依据；仅在低剩余额度且简单方案已核验时保留本地候选句回退。每条仍需外观与双轮盲解析／工具核验。
- 新草稿 `traffic-scene-v1` 优先显著属性／具体类别、真实自车方位和可靠地标；新策略下两条三维关系可联合消歧，新草稿不使用画面排序、二维关系或边缘截断；证据不足补看或换视角／帧，不从截断推断靠近自车。像素方案已唯一也继续预算内竞争对象观察；保留已确认显著特征与有用方位，不强制未知属性，不改旧完成结果和核验门槛。
- 颜色、车型／原生部件、衣着、头盔、形状、显著特征和可靠空间关系联合消歧；可确认且唯一的车辆／行人／标志牌可作地标。未知或冲突属性不排除竞争对象。
- 施工路障细分类别、双色条纹与警示灯进入结构化观察及写作／盲解析词汇；显著特征优先于普通形状。来源相机匿名观察发现主检查遗漏属性且尚无唯一方案时预算内定向复核，不从解释文字直接补证；已排定的竞争对象不占用额外地标名额。
- 新夜景证据 `visible-region-v1` 支持可见点亮前灯／尾灯，完整原图区域检查与车身识别分开；明确同相机、相同输入凭据且已确认无对应可见灯光时才排除该线索的竞争者，未检查／噪声／灯光归属不明仍保留，不推断灯关闭或运动。最小充分方案优先覆盖来源相机；独占点证据满足既有数量／纯度／覆盖／跨度门槛时可独立建立部分可见目标的 2D／3D 关联，防止同目标重复竞争。
- 来源原图中与目标重叠或同边缘的潜在竞争对象优先观察，完整计划与未知池保持；场景关系补看可覆盖地标自身的消歧竞争者，避免仅复查目标候选而漏掉地标证据链。规划假设不作证据，沿用原预算与单批上限，最终仍核验独立地标、真实关系与双轮盲解析。
- 边缘／排序已唯一时，仍按普通线索的竞争池规划预算内属性／地标补看，避免唯一后备提前终止质量改进。完整线索仍失败且原生框与来源投影高度重叠时，记录原生身份冲突并优先换源；重叠只作失败诊断，不合并框、删除竞争者或代替最终唯一性核验。
- 新候选的代表帧／备选排序优先避开近乎重合的同类别原生身份，再比较潜在遮挡、距离和图像大小；保留所有原有合格帧和目标，元数据风险仅用于规划。已有冻结候选与完成记录不改写。
- 新地标支持属性与可靠自车方位、到独立唯一物体的同相机水平关系联合限定，保存限定／依赖并阻止循环引用；未知竞争者保留。来源视角相关对象优先观察，无唯一方案且剩余四次调用时优先保留换视角／同轨迹换帧机会，不增加累计额度。
- 新准备证据采用 `minimal-sufficient-grounding-v1`：真实、有依据且一句话能唯一定位即可；不强制外观数量、细分类型、颜色、自车方向或地标组合。优先属性／自然空间关系，水平排序仅为必要后备。完整来源图像中已确认属性唯一且原生身份已核验时直接提供明确视图的属性方案，不被其他相机无关联小框无条件阻塞；同图未知对象仍保留，原生关系仍用完整原生竞争池。历史完成记录保留原文、证据及冻结规则；外观、身份、唯一性与双轮核验保留。
- 目标身份优先的按需观察：仅调度假设成立且保留完整计划预算时先发目标小批次，实际复核／唯一性证明通过才跳过后续；未观察竞争者不删除。普通补看按相机和输入摘要去重，仅限已有可辨认观察；新证据及不确定性／冲突复核保留。原图仅缓存一个帧、源文件变化失效；原生模型客户端按批次线程复用并关闭，有限总预算通过摘要索引统计。
- 帧级点坐标索引加速框内归属，最终公式与完整点云保持；未确认地标提前退出描述搜索，同一视角复用观察调度，资产哈希有界并发。
- SQLite WAL、事务预留、索引和原子摘要表；调度／展示／指定运行耗时查询避免反复读取全量几何快照。
- 精简详情在读取阶段过滤重型证据与旧准备进度，保留全部计时间隔；投影缓存有界且按事务快照代次核对，覆盖同版本号编辑、删除重建与回滚。精简响应编码置于同步线程，页面隐藏停止展示轮询、返回即刷新，进度更新不重复绘制相同点云；后台任务及完整核验记录保持。
- 批次内有界复用同帧同相机、同供应商／代码／来源组件及完全相同像素上下文的可靠匿名观察，命中重验资产，保留原调用依赖；目标自身、未知和冲突仍新观察，剩余对象重新分组，冷缓存恢复与最后引用删除有回归。官方串行转换仅并发读三个独立雷达组件，读取行与顺序不变；局部实测不代表整批吞吐。
- 每批观察发送前再查已完成的同输入观察，当前批次原位缩小或跳过，保留索引和预留输入；部分复用后已完成请求的冷缓存恢复有回归。图像视角／可见性的既有检查前移到草稿阶段；仅基于确认且为真的单相机事实补写全缺失视角的新草稿，模糊措辞交回模型，仍需外观与双轮盲核验。
- 只读耗时诊断支持按创建顺序 `--recent` 取样，补充响应中位数、图像数、已报告缓存命中与实测输出速率；成功但超过一秒的 API 读取记录脱敏延迟，不把线程累计耗时或响应头计时当作整批吞吐。
- 原生证据准备／换帧最多两路，线程私有读取缓存；小型来源指纹缓存加锁共享，每次核对文件 stat，同文件并发只哈希一次、变更使各读取器失效。官方转换与场景发布仍串行，拿锁后重查同帧、避免重复转换，等待时续期并响应暂停；证据登记单独互斥，全部线程结束再关闭转换 worker，自定义准备器保持串行。并行身份隔离、同帧竞争、索引更新和取消等待纳入既有核心回归。
- HTTP 暂时失败、确定未发送连接和格式错误有界重试；共享冷却、时长检查、样本错误隔离，结果未知请求不重放。
- 可辨认部分出画目标支持实际原图边界定位，明确相机与边缘，同边缘未知竞争者保留；不从派生裁剪边界或表观大小推断。失败目标可明确授权重新入池并追加每目标最多 12 次的一轮额度，跨任务单次消费、暂停继续沿用累计上限；历史账本和成功结果保留，结果未知请求不重放，操作不自动启动。
- 崩溃遗留 running 批次在旧租约过期且配置一致后恢复；主动暂停／停止／未启动不自动执行。人工继续在原任务冻结新执行修订，保留成功结果和累计额度，未完成工作从样本起点重做。后端源码更新须先由用户重启。
- 显式开始时可持久化排队，按开始点击顺序接续，去重及取消单项；当前任务暂停／停止或共享故障会挂起队列，继续后恢复。重启保留排队；代码／目录／模型变化时先暂停，需重新开始确认。刷新／关闭网页不停止后端。
- 随机／按索引人工审核、定位确认、拒绝／废弃及带反馈返工；明确返工在原任务内重试，禁止新建任务，按版本／反馈单次分配最多 12 次新调用，历史费用保留，反馈与旧描述进入生成上下文，新描述仍需双轮核验，通过后计入原任务；已达目标时先手动删除一条有效标注再返工；自动未通过的当前版本经正确定位确认和明确人工审批后可纳入可用集与导出；自动失败记录保留，文本／帧／目标变化使审批失效，身份和资源校验保持。
- 按勾选范围删除任务；存续任务继承必要账本与运行引用，最后关联任务删除后清理无引用历史。无关任务可继续运行，删除令牌不因无关进度失效；活动执行器期间保护共用缓存。
- 删除可选是否重新开放已处理轨迹；含已完成任务默认保留轻量排除记录，未完成任务默认重新开放，未处理候选不受影响。确认令牌绑定选择，排队任务派发前检查；历史导出 samples.jsonl 可一次性恢复排除记录，临时清单不作为运行依赖。
- 删除后台进度、引用摘要缓存与终态索引；慢扫描、文件暂存和清理均移出写事务。提交前复核变化引用，新增关联会回滚恢复；并发回归要求另一任务在文件暂存期间完成保存与租约续期。历史记录首次建缓存仍可能耗时，不把局部计时当作全量性能保证。
- 训练／验证任务候选按真实官方来源分开；返工继承类型，混选或导出类型不符提前拒绝；场景保留实际 official_split，软件回归覆盖验证集 ZIP、读取与合并。
- 公开精简 ZIP、每轨迹最新有效标注、分包增量合并、去重、资源／版本冲突拒绝、兄弟集合 context 隔离与失败回滚。
- 独立盲评、冻结报告、配对修复比较和受控认证发布，与日常审核分开计量。

- 完整场景盲定位歧义复核：符号歧义且外观／身份通过时，在原额度内执行两轮完整原图与全部匿名候选盲定位；逐轮换编号，无目标提示，不删除未知对象，保留自动模型核验协议。人工审批单独绑定当前版本并计入任务可用数量，原自动失败与费用记录保持；导出仍核验身份、原图、点云、监督和官方划分。

## 验证如何解读

后端维持 `tests/test_core.py` 的 10 个核心用例；前端现有 lint、build 和 Node 交互检查。具体本轮结果在对话中报告，不另增验证总结文档。

软件回归覆盖恢复、额度、防重复请求、删除引用保护，以及导出读取、合并、去重与冲突。真实模型请求、冻结证据回放、局部性能基准和独立盲评属于不同证据，不混称独立认证；局部速度倍数不代表全流程吞吐倍数。

开发核验和失败运行只要仍有引用或累计调用，就属于持久化记录，不能按“旧缓存”删除。原始数据与内部来源／方法指纹也不为清理而重置。

## 后续工作

1. 整批吞吐、模型／换帧等待、资源占用及连续运行恢复能力的真实测量。
2. 新场景独立人工盲评、方法校准、跨片段泛化和消融；不能承诺可标注对象零遗漏。
3. 使用真实官方 validation 文件完成转换环境与标注实跑验收；读取／转换路径和分开导出已有软件回归，不从 training 随机拆分。
4. 建筑／树木等自由地标的可靠身份和关系证据链，目前不支持随意写入。

下游网络、训练适配和训练后的 3D／BEV Acc 暂不在本项目范围。后续优化不得以删除未知竞争对象、放宽核验或改动公开训练契约换取速度或通过率。
