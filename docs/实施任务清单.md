# 实施现状与后续工作

本文记录当前功能、验证范围和待开展的工作。数据规模、任务状态、调用额度和实际模型以对应运行记录为准。

## 已实现

| 范围 | 当前能力 |
| --- | --- |
| 数据准备 | 按 Waymo 官方划分管理训练集和验证集，冻结候选目录，按需转换完整单帧点云 |
| 自动标注 | 核实原图、原生目标身份及几何关系，生成英文描述，通过两轮盲定位核验唯一性 |
| 任务管理 | 持久化排队、暂停、继续和异常恢复，分别记录进度与累计模型调用 |
| 审核与返工 | 人工定位、审批、拒绝和废弃，反馈在原任务内返工，标注版本与审核记录可追溯 |
| 数据导出 | 生成 Waymo-3DRef 精简包，提供独立加载、增量合并、去重及冲突检查 |
| 质量评估 | 冻结评估样本、独立人工盲评、汇总指标和受控数据发布 |

标注证据、身份链和公开数据契约见[技术方案](waymo-3dvg-agent技术方案.md)。工作台流程见[使用与验收](标注Agent开发.md)。

## 验证范围

- **软件回归**覆盖定位核验、恢复与调用额度、删除引用保护、训练数据读取和合并。运行命令见 [README](../README.md#开发与验证)。
- **端到端运行**应记录实际数据划分、模型配置、冻结执行方法以及处理、通过和失败数量。性能报告同时注明样本范围、调度设置、调用数与耗时。
- **独立质量评估**使用冻结样本和独立审核流程，分别报告评估范围、指标分母及不确定性。详见[科研验收协议](科研验收协议.md)。

## 后续工作

1. 在不同驾驶片段和官方验证集上扩大端到端评估，记录对象类型、可见性和失败原因。
2. 评估整批吞吐、资源占用、长时间运行和异常恢复，区分转换、模型调用及其他等待时间。
3. 在冻结方法、输入和预算的条件下开展独立盲评与消融实验，验证跨片段表现。
4. 为建筑、树木等当前缺少可靠身份链的地标研究可验证的原生几何与图像关联。

本项目交付标注、审核和数据工具。时序视觉定位、下游训练和自由三维框预测评测由后续项目承担。
